# Kangaroo Math Hub

静态数学袋鼠题库，直接打开 `index.html` 即可使用，无构建步骤。

## 题库

- 1999：Grade 3–4，共 24 题。
- 2002：Grade 5–6，共 30 题。
- `site_data.js` 是网页使用的题目数据；`data/` 是原始整理数据。
- `hints.js` 按年份和题号提供每题三条递进提示，并设置题目的年级。
- `diagrams.js` 提供部分题目的教学参考图解。现有题库部分题目仍引用原卷图片；参考图解不是完整的原卷题图。

## 使用

- 浏览区一次显示一题。上下滚动、手机上下滑动或底部按钮切题；长题先滚动内容，到边缘后切题。
- 可按试卷、文字和标签筛选，或通过单题查看输入题号。
- 右上角切换教学版／练习版。教学版保留答案、详解、思路、图解和备课提示；练习版题目操作仅提供 Hint，点击选项直接判题，正确绿色、错误红色。
- 每次显示 Hint 都先确认，只显示当前一条，按 1 → 2 → 3 → 1 循环。取消不推进。
- 当前页面会记住各题的作答和 Hint 位置，切题或筛选不会清除；刷新页面后重置。
- 切入练习版会关闭教学答案和详解，并退出全卷答案视图。

## 验证

`verify.cjs` 使用 Playwright 和本机 Edge 验证题库年级、单题显示、滚动导航、模式隔离、答案反馈、Hint 确认与循环、筛选以及手机宽度。

安装 Playwright 后运行 `node verify.cjs`；也可用 `PLAYWRIGHT_MODULE` 环境变量指定已有 Playwright 模块路径。
