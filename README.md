# Kangaroo Math Hub

## 协作约定

用户要求：每次完成项目修改并验证后，自动提交并 push 到当前远程分支，无需再次提醒。仅提交本次相关改动，不包含无关的未跟踪文件。

静态数学袋鼠题库，直接打开 `index.html` 即可使用，无构建步骤。

## 使用

- 浏览区连续显示多题，自然上下滚动；也保留单题查看。
- 可按试卷、文字和标签筛选，或通过单题查看输入题号。
- 点击题目标签或顶部标签筛选时，自动切换到全部试卷的题目列表，暂时清空文字搜索，显示所有年份的同类题。顶部已选标签可点击取消（支持键盘 Enter／空格）；取消一个标签时保留其他标签，取消最后一个后恢复首次选择标签前的试卷、视图、题号和搜索条件，并定位回原题。连续增减标签不会覆盖最初的返回位置。
- 右上角切换教学版／练习版。教学版保留答案、详解、思路、图解和备课提示；练习版题目操作提供 Hint 和延申拓展，点击原题选项直接判题，正确绿色、错误红色。
- 每题的“延申拓展”按钮可展开／收起对应拓展题，方法提示和答案解析分别默认折叠。两个模式均可使用，查看拓展答案不会显示原题答案。拓展题展开状态在当前页面筛选、切题时保留；重新渲染时收起内部提示和解析，刷新后全部重置。
- 教学版默认隐藏 Hint，点击“显示 Hint”后一次展开全部，再次点击可隐藏。编辑按钮位于展开的 Hint 框内，可编辑、添加或删除，至少保留一条。自定义内容保存到当前浏览器 localStorage，刷新保留，不同步到其他设备。练习版每次显示 Hint 都先确认，按顺序逐条循环，取消不推进；使用编辑后的内容。
- 当前页面会记住各题的作答和 Hint 位置，切题或筛选不会清除；刷新页面后重置。
- 教学版与练习版均可点击选项即时判题：正确绿色、错误红色，可重新选择；作答记录在两种模式间保留。点击选项保留已展开的讲解和拓展内容；隐藏教学答案不会清除已经答对的绿色反馈。
- 切入练习版会关闭教学答案和详解，并退出全卷答案视图。
- 右上角用可点击的模式标签显示“教学版”或“练习版”，点击即可切换。练习版展开拓展题的“同类方法提示”或“拓展答案与解析”前须确认，取消则保持折叠；收起无需确认，重新展开再次确认。Hint 按钮未查看时为白色，确认查看后为蓝色，教学版收起后恢复白色。

## 验证

`verify.cjs` 使用 Playwright 和本机 Edge 验证题库年级、多题显示、Hint 编辑与持久化、模式隔离、答案反馈、Hint 确认与循环、筛选以及手机宽度；逐题检查所有已加载的拓展题的内容映射、展开收起、折叠答案、键盘操作，并对数位、三角形、角度、整除及计数类拓展答案作独立枚举核对。`verify-paper.cjs` 专门验证 1999 G5–6 卷、同年不同年级状态隔离、原图加载、问题题目不误判、原有标签复用及数据纠错。`verify-2000.cjs` 验证 2000 G3–4 的 24 题答案、分值、教学字段、8 张原图、独立作答与 Hint 状态、练习版确认及全部题目的手机布局，并独立核对删数与钟表题。

安装 Playwright 后运行 `node verify.cjs`；也可用 `PLAYWRIGHT_MODULE` 环境变量指定已有 Playwright 模块路径。

教学版备课提示默认折叠；Hint、答案、详解、思路、图解、备课提示及顶部全局展开按钮统一使用固定标签和旋转箭头，展开与关闭带过渡效果，遵循系统减少动态效果设置。


`verify-imports.cjs` 核对新增五六年级试卷的全部答案、教学字段、确切题图清单、图片加载、独立作答状态与手机布局；可传入试卷 ID 单独检查。原卷 PDF 在 `past papers/` 本地保留，由 `.gitignore` 排除。
